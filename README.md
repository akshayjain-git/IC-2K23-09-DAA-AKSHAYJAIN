This repository contains the programs completed as part of the Design and Analysis of Algorithms (DAA) assignment. The programs are implemented in **C++** and organized unit-wise according to the course topics.

## Unit-wise Contents

| Unit | Topic | Programs |
|---|---|---|
| UNIT-01 | Introduction Algorithms | Linear Search, Iterative Binary Search, Recursive Binary Search, Selection Sort |
| UNIT-02 | Divide and Conquer | Maximum and Minimum, Quick Sort, Merge Sort, Insertion Sort |
| UNIT-03 | Greedy Method | Fractional Knapsack, Job Sequencing, Prim's Algorithm, Kruskal's Algorithm |
| UNIT-04 | Dynamic Programming | 0/1 Knapsack, Memoized Fibonacci Series |
| UNIT-05 | Traversal and Search | Depth First Search (DFS), Breadth First Search (BFS) |
| UNIT-06 | Backtracking | 8-Queens Problem |
| UNIT-07 | NP Hard NP Complete | Travelling Salesman Problem |

The objective of these assignments is to implement and understand important algorithm design techniques including divide and conquer, greedy algorithms, dynamic programming, graph traversal, backtracking, and NP-hard problems.
